## Featured projects

### IP Traffic Forecasting with Machine Learning

Research repository developed from my master's thesis at Universidad Miguel Hernández, defended with a grade of **10/10**.

The project compares statistical, machine-learning and deep-learning approaches for **multihorizon IP traffic forecasting** on UGR'16, using a temporally separated **March → April → June** protocol with external evaluation, cross-family analysis, residual diagnostics, and reproducibility documentation.

Model families include **ARIMA, VAR, Ridge, tree ensembles, RNN, LSTM, GRU, and a lightweight Transformer**. The final evidence supports no universal winner: performance depends on forecast horizon, metric, temporal regime, training history, stability, and computational cost.

[Explore the repository →](https://github.com/Narvalaina/ip-traffic-forecasting-ml)

### SDN Fat-Tree Testbed

Reproducible SDN testbed developed from my bachelor's thesis at Universidad Miguel Hernández, defended with a grade of **10/10**.

The project covers incremental validation from basic topologies to Leaf-Spine and a **Fat-Tree k=4**, deterministic OpenDaylight RESTCONF forwarding, bounded OpenFlow `select`-group ECMP experiments, reproducibility checks, and public engineering evidence.

[Explore the repository →](https://github.com/Narvalaina/sdn-fattree-testbed)
